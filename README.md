# Student Performance Prediction

This project uses **Supervised Machine Learning** to predict student performance based on academic and other related factors.

### Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook / Google Colab

### Algorithm

Linear Regression

### Objective

To predict student performance and understand the factors that may affect their academic results.
